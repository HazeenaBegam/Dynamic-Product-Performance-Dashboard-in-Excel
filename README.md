# Dynamic Product Performance Dashboard in Excel

## 📊 Project Overview
This project demonstrates how raw sales data can be transformed into an **interactive dashboard** using Excel’s advanced features. It highlights my ability to design professional, BI-style dashboards that are both visually appealing and analytically powerful.

## 🚀 Features
- **PivotTables** for multi-dimensional analysis of product and region performance  
- **Timeline slicer** integrated with product/region slicers for dynamic filtering  
- **Conditional formatting** to highlight trends and anomalies instantly  
- **PivotCharts** for clear and interactive data visualization  
- Responsive design for easy navigation and exploration  

## 🎯 Skills Demonstrated
- Data cleaning and structuring for analytics  
- Advanced Excel functions (PivotTable, PivotChart, Slicers)  
- Dashboard design principles (clarity, usability, interactivity)  
- Business storytelling through visuals
